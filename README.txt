Put your image files in this folder with these exact names:

  hero.jpg        -> homepage full-screen background still
  still-1.jpg      -> gallery
  still-2.jpg      -> gallery
  still-3.jpg      -> gallery
  still-4.jpg      -> gallery
  still-5.jpg      -> gallery
  still-6.jpg      -> gallery
  poster.jpg       -> official poster (Press section)

Then open index.html in a text editor, find the matching
commented-out <img> line for each spot, and uncomment it
(remove the <!-- and -->) so the real image shows instead
of the placeholder texture.

Full instructions are also written at the top of index.html itself.
